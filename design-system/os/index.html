Two-pane filesystem explorer

Jottacloud side

Same — This path exists in the local index at the same path.
Moved — Found in the local index under a different path (same name and size).
Maybe — A file with the same name exists locally, but the size differs.
Partial — Folder has a mix of present and missing children.
Missing — No matching path, name or size was found in the local index.

Local side

In Jottacloud — This local item exists at the same path in Jottacloud.
Moved match — This local item is the match for a moved Jottacloud item.
Local only — Present in the index but not found anywhere in Jottacloud.
Not in Jottacloud — No same-path counterpart in Jottacloud; it may still have matched another item.
Type differs — A file/folder with the same name exists on the other side.
